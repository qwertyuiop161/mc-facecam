BEHOLD YOUR FACE IN MINECRAFT!!!

This project uses sarxos on fabric 26.3 to do this:

create a new command, livestream, either livestream stop or livestram int int int

when you do livestream int int int, it creates a screen at those coordinates, which uses the webcam capture in sarxos to create your cam, shrink to 128x128, send to the server, which finds the average color and creates a particle of that color every second

livestream stop stops it and removes it

Note: it is very laggy and prob wont work as well on older machines, and you need to have particles: all
